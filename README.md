# 🌌 Horizonte Estelar  
### Um site interativo sobre o Sistema Solar com jogo de caça-palavras e dashboard de desempenho

![Logo Horizonte Estelar](/web-data-viz/public/css/img/logo_preta.png)

O **Horizonte Estelar** é um projeto desenvolvido com o objetivo de aproximar o usuário do universo do espaço por meio de curiosidades, imagens, um jogo interativo e uma dashboard com indicadores de desempenho.  
Criado utilizando **HTML, CSS e JavaScript**, o sistema integra a **API Web-Data-Viz** para comunicação com o banco de dados, permitindo **cadastro, login, registro de pontuação e visualização de métricas**.

---

## 🚀 Descrição do Projeto
O projeto consiste em um site de curiosidades sobre o Sistema Solar, trazendo informações resumidas sobre os planetas e oferecendo uma experiência divertida por meio de um jogo estilo **caça-palavras**.  
A pontuação da partida é registrada e exibida em uma **dashboard**, permitindo ao usuário acompanhar:

- Palavras encontradas  
- Meta do jogo 
- Palavras escondidas  
- Quantidade total de partidas jogadas  

Além disso, o projeto conta com autenticação de: **cadastro, login, e logout**.

---

## 🎯 Objetivo
Cativar o usuário com conteúdo acessível, visualmente agradável e interativo, aproximando-o do tema espacial, além de aprimorar habilidades na área de tecnologia e programação.

---

## 🧩 Funcionalidades

### Requisitos Funcionais
- Cadastro de usuários  
- Login e autenticação  
- Exibição de curiosidades sobre os planetas  
- Navegação entre Home, Cadastro, Login,Sobre mim, Dashboard e Game  
- Jogo de caça-palavras espacial  
- Registro da pontuação do jogador  
- Dashboard com gráficos usando Web-Data-Viz  
- Integração com banco de dados  
- Validação de campos  
- Logout
